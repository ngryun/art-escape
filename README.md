# 밤의 미술관 탈출

학기 초에 학생들이 미술 교과서(미진사 『고등학교 미술 창작』)를 직접 펼쳐 보도록 만든 3D 웹 방탈출 게임입니다.
다섯 개의 3D 전시실을 360도로 둘러보며 스포트라이트를 받는 **교과서 속 작품**을 찾고, 그 작품이 실린 **교과서 쪽 번호**로 출구 자물쇠를 엽니다.

## 기능

- **3D 전시실 5개**: 화면을 끌어서 둘러보고, 작품·문·안내판을 눌러 조사합니다. 휴대폰에서는 두 손가락으로 확대할 수 있습니다.
- **방마다 다른 분위기**: 물빛 전시실, 빛의 방, 한국화 전시실, 미디어 아트홀, 경매장.
- **힌트**: 오답 1·3·5회 후 작품 이름, 단원, 쪽 범위가 차례로 열립니다.
- **타이머와 기록**: 걸린 시간, 오답 수, 힌트 사용 수를 보여 줍니다.
- **탈출 인증 코드**: 탈출하면 이름과 시간으로 만든 6자리 코드가 나옵니다.
- **이어 하기**: 새로고침해도 같은 기기에서는 멈춘 방부터 이어집니다.
- **정답 숨기기**: 정답 쪽 번호는 해시로만 들어 있어 소스 보기로 알 수 없습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 화면 |
| `app.js` | 3D 전시실과 게임 진행 (three.js r128) |
| `questions.js` | 방별 작품 이미지, 힌트, 정답 해시 |
| `images/` | 교과서에서 꺼낸 작품 이미지 |
| `common.js` | 해시와 인증 코드 함수 |
| `style.css` | 디자인 |
| `verify.html` | 교사용 인증 코드 확인 |
| `tools/make-hash.html` | 교사용 정답 해시 생성기 |

## 교사용 페이지

배포 주소 뒤에 붙여서 엽니다. 게임 화면에는 링크가 없습니다.

- 인증 코드 확인: `https://<계정>.github.io/<저장소>/verify.html`
- 정답 해시 만들기: `https://<계정>.github.io/<저장소>/tools/make-hash.html`

## 작품 바꾸기

1. 새 작품 이미지를 `images/room번호.jpg`로 저장합니다.
2. `tools/make-hash.html`에서 방 번호와 정답 쪽으로 해시를 만듭니다.
3. `questions.js`에서 그 방의 `hash`, `hints`, `found`를 고칩니다. `theme`, `art`, `door`로 분위기와 작품·문의 벽 위치도 바꿀 수 있습니다.

## GitHub Pages 배포

1. 저장소를 만들고 이 폴더를 올립니다.

   ```bash
   gh repo create art-escape --public --source . --remote origin --push
   ```

2. Pages를 켭니다.

   ```bash
   gh api -X POST repos/<계정>/art-escape/pages -f "source[branch]=main" -f "source[path]=/"
   ```

3. 1~2분 뒤 `https://<계정>.github.io/art-escape/` 에서 열립니다.

## 알아 둘 점

- **저작권**: `images/`의 작품 사진은 교과서에서 가져온 저작물입니다. 공개 저장소에 올리면 누구나 볼 수 있으니, 수업 목적 범위에서 쓰고 필요하면 저장소를 비공개로 바꾸거나 수업 뒤 내려 주세요.
- 교과서 PDF와 `문제_정답표.md`는 `.gitignore`로 제외되어 GitHub에 올라가지 않습니다.
- 3D 화면은 WebGL을 씁니다. 크롬·엣지·사파리 최신 버전에서 동작합니다.
- 이미지를 불러오려면 웹 서버가 필요합니다. 파일을 더블클릭해 열면 작품이 안 보일 수 있습니다. 로컬에서는 아래 명령으로 미리 봅니다.

  ```bash
  python -m http.server 8123
  ```

- 인증 코드는 학생이 숫자만 바꿔 꾸며 내는 것을 막는 정도입니다. 성적 평가용으로는 쓰지 마세요.
