# 밤의 미술관 탈출

학기 초에 학생들이 미술 교과서(미진사 『고등학교 미술 창작』)를 직접 펼쳐 보도록 만든 웹 방탈출 게임입니다.
전시실마다 교과서 내용을 묻고, 그 내용이 실린 **쪽 번호**를 입력하면 다음 전시실로 넘어갑니다. 모두 5단계입니다.

## 기능

- **5개 전시실**: 1·5·9·15·18단원에서 한 문제씩 나옵니다.
- **힌트**: 오답 2회 후 힌트 1(단원 이름), 오답 4회 후 힌트 2(쪽 범위)가 열립니다.
- **타이머와 기록**: 입장부터 탈출까지 걸린 시간, 오답 수, 힌트 사용 수를 보여 줍니다.
- **탈출 인증 코드**: 탈출하면 이름과 시간으로 만든 6자리 코드가 나옵니다.
- **이어 하기**: 새로고침하거나 창을 닫아도 같은 기기에서는 멈춘 방부터 이어집니다.
- **정답 숨기기**: 정답 쪽 번호는 코드에 해시로만 들어 있어 소스 보기로 알 수 없습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 화면 |
| `questions.js` | 문제, 힌트, 정답 해시 |
| `app.js` | 게임 진행 로직 |
| `common.js` | 해시와 인증 코드 함수 |
| `style.css` | 디자인 |
| `verify.html` | 교사용 인증 코드 확인 |
| `tools/make-hash.html` | 교사용 정답 해시 생성기 |

## 교사용 페이지

배포 주소 뒤에 붙여서 엽니다. 게임 화면에는 링크가 없습니다.

- 인증 코드 확인: `https://<계정>.github.io/<저장소>/verify.html`
  학생 화면의 이름, 탈출 시간, 코드를 넣으면 진짜인지 알려 줍니다.
- 정답 해시 만들기: `https://<계정>.github.io/<저장소>/tools/make-hash.html`

## 문제 바꾸기

1. `tools/make-hash.html`에서 방 번호와 정답 쪽을 넣어 해시를 만듭니다.
2. `questions.js`에서 그 방의 `hash`, `question`, `hint1`, `hint2`, `found`를 고칩니다.
3. 커밋하고 push하면 1~2분 뒤 사이트에 반영됩니다.

## GitHub Pages 배포

1. github.com에서 **New repository**를 만듭니다. 이름 예시는 `art-escape`, 공개 범위는 Public입니다.
2. 이 폴더에서 아래 명령을 실행합니다. `<계정>`은 본인 GitHub 아이디로 바꿉니다.

   ```bash
   git remote add origin https://github.com/<계정>/art-escape.git
   git push -u origin main
   ```

3. 저장소의 **Settings → Pages**에서 Source를 *Deploy from a branch*, Branch를 `main` / `(root)`로 두고 저장합니다.
4. 1~2분 뒤 `https://<계정>.github.io/art-escape/` 에서 열립니다.

## 알아 둘 점

- 교과서 PDF와 `문제_정답표.md`는 `.gitignore`로 제외되어 GitHub에 올라가지 않습니다.
- 인증 코드는 학생이 숫자만 바꿔 꾸며 내는 것을 막는 정도의 장치입니다. 코드를 깊이 분석하면 만들어 낼 수 있으니 성적 평가용으로는 쓰지 마세요.
- 진행 기록은 학생 기기의 브라우저에만 저장됩니다. 다른 기기로 옮기면 처음부터 시작합니다.
- 로컬에서 미리 보려면 이 폴더에서 아래 명령을 실행하고 `http://localhost:8123`을 엽니다.

  ```bash
  python -m http.server 8123
  ```
